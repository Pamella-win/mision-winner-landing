# Misión Winner · Landing Page

Landing page interactiva de una sola página que presenta el programa **Misión Winner** (WIN Capacitación): objetivo del programa, rutas de aprendizaje (ATC ONE, NOVA FIDELIS, Ventas Omega) y resultados de un año de maduración operativa.

- Archivo único autosuficiente: `index.html` (HTML + CSS + JS vanilla, sin dependencias externas salvo la fuente Nunito de Google Fonts).
- Animaciones: contador de estadísticas al hacer scroll, tabs de misiones por canal con tooltip, carrusel de testimonios reales (anonimizados) de la encuesta de satisfacción del programa.
- Paleta e identidad visual: Misión Winner / WIN (naranja `#FF5A00`, amarillo `#FFC200`, morado `#5B28AF`, azul `#0E1C80`).

## Ver en local

Abre `index.html` directamente en el navegador — no requiere servidor ni build.

## Publicar con GitHub Pages

1. Settings → Pages → Source: `main` branch, carpeta `/ (root)`.
2. La página quedará disponible en `https://<usuario>.github.io/<repo>/`.
